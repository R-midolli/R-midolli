# 👋 Bonjour, moi c’est Rafael

### 🎯 Business Analyst / Data Analyst | PGC (FMCG) & Retail | Data → Décision
📍 Basé en France 🇫🇷

Je transforme des données commerciales et opérationnelles (sell-in/sell-out, pricing, promotions, distribution, supply chain) en **KPI fiables**, **modèles data propres** et **dashboards actionnables**.

---

## 🚀 Ce que vous trouverez ici
- 📦 **Projets end-to-end (ELT/BI)** : ingestion → modélisation → tests → reporting  
- 🧱 **Modélisation analytique** : schémas en étoile, tables facts/dims, couche “gold” prête pour BI  
- ✅ **Data quality** : tests dbt (not_null, unique, relationships), traçabilité et docs générées  
- 📊 **Power BI** : dashboards “one-page executive” + modèle sémantique clair
